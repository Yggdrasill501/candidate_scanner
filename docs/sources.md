# Data sources

Verified live on 2026-10-23 from a residential connection in Slovakia. Verdicts: **USABLE**, **CAVEATS** (usable with the noted limits), **NO** (not usable now). Test names were public officials only (Marek Hattas, mayor of Nitra; Branislav Becík, NSK chair).

Identity rule of thumb: most sources carry only a name. Sources marked **ID+** carry a birth date or birth year and can confirm identity. Birth dates and street addresses are used for matching only and are never published.
